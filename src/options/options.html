NQFM Helper — Settings

Cost (team size)

Used as the denominator in the Score calculation.

MoSCoW story value modifiers

Story Value = Story Points × modifier for the ticket's MoSCoW label.

LabelModifier

Alternate "Done" statuses

Comma-separated Jira status names that count as complete for the Alternate metrics (e.g. for OvrC's 3-week release cycle).

Is OvrC auto-detection

Tickets whose summary contains this keyword default to "Is OvrC" = true. (Jira's sprint report data doesn't include labels, so label-based detection isn't available yet.)

Default board (for the popup)

Only used if the popup hasn't yet seen you visit a sprint report page. Find the rapidView id in your board's URL, e.g. rapidView=670.

Sprint history length

How many recent sprints the popup pulls into its dropdown / month blend.
